# WorkSmart AI — AI-Powered Workplace Productivity Assistant

## Project overview
WorkSmart AI is a responsive workplace productivity assistant prototype. It demonstrates how AI-inspired tools can support everyday work such as drafting emails, organising meeting notes, planning tasks, structuring research, and answering common productivity questions.

## Features
- **Email assistant:** creates a professional email draft from a purpose, recipient, tone, and details.
- **Meeting summariser:** organises supplied notes into a summary and potential action items.
- **Task planner:** lets users add, prioritise, complete, and delete tasks during the current session.
- **Research helper:** structures a research brief and can organise text supplied by the user.
- **Workplace chatbot:** provides rule-based guidance for common workplace productivity questions.
- Responsive dashboard and copy-to-clipboard controls.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern browser such as Chrome or Edge.

No package installation or build step is required.

## Publish with GitHub Pages
1. Push the project files to the `main` branch.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for deployment and use the URL shown in the Pages settings.

## AI functionality and limitations
**Important:** This version is a front-end prototype. It does not connect to a live AI model or browse the internet. Email and meeting outputs use simple templates/text organisation; the chatbot uses predefined rules. The research helper provides a structure and only summarises text supplied by the user. Do not describe these as live AI integrations.

A future version could connect to a language model through a secure backend. Never put a private API key in browser-side JavaScript or commit secrets to GitHub.

## Responsible AI
- Do not enter passwords, confidential workplace information, or sensitive personal data.
- Review all generated text before sending or sharing it.
- Verify research claims against reliable, current sources.
- Check for bias and incorrect assumptions.
- Keep people responsible for decisions and final approvals.

Created as a learning project for an AI Skills Program to demonstrate workplace productivity concepts, prompt design, front-end development, and responsible use of AI.
